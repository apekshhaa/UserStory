# Employee Data Ingestion Pipeline

## Objective
Scrape employee data from the API and perform data normalization.

## Features
- API data retrieval
- JSON validation
- Full Name generation
- Designation mapping
- Phone number validation
- CSV export
- Error handling and retry mechanism
- Unit testing

## Installation

pip install -r requirements.txt

## Run

python src/main.py

## Run Tests

python -m unittest discover tests
